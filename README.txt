# CSIT Freshers '26 — Dark Aesthetic Invitation Website

## Quick start
1. Keep the folder structure unchanged.
2. Open `index.html` in a browser.
3. The invitation details are already set to 26 September 2026, 1 PM - 4 PM, Seminar Hall.

## For your college presentation
- Put this website on the projector/full-screen browser.
- Show the hero section while introducing the Freshers Party.
- Scroll to the invitation section to show the official invitation artwork.
- For deployment, upload the folder to GitHub + Vercel, Netlify, or another static host.

## Design
Dark cinematic aesthetic, rose-gold accent, animated particles, subtle grain, responsive layout, and scroll reveal animations.
